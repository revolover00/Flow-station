# Flow Station · مكتب المذاكرة

مكتب مذاكرة عربي يبدأ فاتحًا وفاضيًا. اختار أدوات الجلسة بنفسك: ملف، نوتة، بومودورو، Calcios، فيديو Youtubiy، ترجمة، مساعد Gemini، ومتصفّح مصادر. الجلسة النموذجية اختيارية. التصميم أصلي مستوحى من المراجع المتفق عليها، وليس نسخة من واجهة Morphic.

## تشغيل محلي

يتطلب Node.js 20.19+ (أو Node 22 LTS). نفّذ `npm ci` ثم `npm run dev`. لإنشاء نسخة الإنتاج: `npm run build` ثم `npm run preview`. مسارات `/api/*` شغّالة بنفس الـorigin في التطوير والمعاينة عن طريق Vite middleware، وفي النشر عن طريق `api/[action].js`. لا تكتفِ برفع `dist` لو محتاج الخدمات الذكية.

## ما يعمل من غير حساب أو مفاتيح

- الجلسات وأسماء الأدوات ومقاسات الألواح والنوتس والمراجع محفوظة على الجهاز. الواجهة هاتف: أداة واحدة، تابلت كبير/ديسكتوب: لوحان يمكن فصل مساحتيهما بالسحب أو سهمي الكيبورد. اختيار الوضع الغامق محفوظ، و`prefers-reduced-motion` محترم.
- قارئ PDF باستخدام PDF.js محليًا، صفحات فعلية، عرض نصّي قابل للتحديد، صور JPG/PNG/WebP ونصوص TXT/MD/CSV. اختيار صفحة أو اقتباس ثم «ترجم» / «اسأل» / «اقتبس». الملفات في IndexedDB؛ بيانات الجلسة في localStorage. لا مزامنة سحابية في هذا الإصدار. الصور الممسوحة في PDF من غير طبقة نص تحتاج OCR، غير مشمول هنا. ملفات Office ليست مدعومة حاليًا.
- نوتس Markdown قابلة للتصدير، واقتباسات تُرجعك للصفحة أو لتوقيت الفيديو. بومودورو يدعم إيقاف/استكمال وتغيير المدة؛ يعتمد على وقت الانتهاء الفعلي مش عدد نبضات الشاشة.
- نسخة محلية من آلة **Calcios** الكاملة. الحساب لا يحتاج إنترنت. زر حفظ آخر نتيجة COMP يحتفظ بالمعادلة والنتيجة في دفتر الجلسة.
- الفيديو يعتمد على أسلوب المشغّل الرسمي الموجود في **Youtubiy** مع التحقق من مصدر رسائل المشغّل. يتطلب اتصالًا بالإنترنت، ورابط فيديو يسمح بالتضمين. لا يوجد feed أو تنزيل. سجل التوقيت يتحدّث أثناء التشغيل والنوتة تلتقط آخر توقيت مستلم.
- متصفّح الدراسة: عنوان/بحث، رجوع وتقدّم، حفظ مصادر، معاينة HTTPS معزولة، ورابط للأصل. المواقع اللي بتمنع التضمين أو بتحتاج تسجيل دخول تُفتح خارجيًا. لا يوجد خادم وسيط يعيد نشر الصفحات أو يتجاوز سياساتها. بحث ويكيبيديا اختياري من المتصفح ومن غير مفاتيح.

## الخدمات: ضع القيم على السيرفر فقط

انسخ `.env.example` إلى `.env.local` محليًا، أو أدخل القيم في **Project Settings → Environment Variables** عند النشر ثم أعد التشغيل/النشر. لا تستخدم بادئة `VITE_` للمفاتيح ولا تضفها في Git. صفحة «الربط» تعرض وجود الإعداد من غير عرض قيمته، وليست اختبار صلاحية للمزوّد.

### نشر تجريبي آمن

استورد الريبو في Vercel باستخدام Vite. الخرج `dist`، ودوال `api` تعمل على Node. نشر الأدوات المحلية لا يحتاج مفاتيح. عند توصيل خدمات بحصص في Vercel ضع **`FLOW_ACCESS_CODE`** خاصًا بالنسخة التجريبية، ثم افتح «الربط» وأدخل **رمز الدخول فقط** في التبويب. تظل مفاتيح المزوّد على السيرفر. للاستخدام العام الواعي بالتكلفة يوجد `ALLOW_PUBLIC_AI=true`، ولا ننصح بتفعيله قبل إضافة مصادقة، وحدود استخدام دائمة وتنبيهات ميزانية عند المزوّد. محدِّد السرعة الحالي محلي لكل instance وليس سقف فاتورة عالميًا. لا يتم تسجيل الصور أو الأسئلة أو ردود المزوّد في سجلات التطبيق.

### فحص سريع

1. افتح جلسة فاضية وأضف النوتة والمؤقّت. اكتب ملاحظة وغيّر العرض، ثم حدّث الصفحة.
2. جرّب الجلسة النموذجية، حدّد نصًا، واحفظ اقتباسًا. على الهاتف اضغط شارة المصدر وارجع للملف. اختبر PDF محليًا بالصفحات ووضع النص.
3. افتح Calcios، احسب في وضع COMP ثم احفظ النتيجة. اختبر رفع صورة للسكانر **بعد** ضبط Groq.
4. افتح «الربط» للتحقق من الإعدادات؛ بعد إدخال المفاتيح اختبر ترجمة قصيرة، سؤال Gemini، وصورة معادلة. بدون المفاتيح ستظهر حالة عدم الربط، وليس نتيجة تجريبية على أنها حقيقية.
5. `npm test`: اختبارات الموديل المحلي، التحقق من الطلبات، محوّلات المزوّدين بأجوبة mock، وعزل القيم السرية. `npm run build`: بناء الصفحتين وPDF worker.
